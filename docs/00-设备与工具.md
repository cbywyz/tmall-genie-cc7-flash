# 00 · 设备信息与工具清单

## 设备规格

| 项 | 值 | 怎么确认的 |
|---|---|---|
| 型号 | 天猫精灵 CC7（TG_S2B） | 机身铭牌 / `getprop ro.product.model` |
| SoC | MediaTek MT8167（HW-CODE `0x8167`） | MTKClient 读芯片信息 |
| eMMC | 8GTF4R，用户分区 7.28 GiB | MTKClient 读分区表 |
| 系统 | Android 8.1（treble） | `getprop ro.build.version.release` |
| ABI | armeabi-v7a（**arm，不是 arm64**） | `getprop ro.product.cpu.abi` |
| USB VID:PID | 正常模式 `0E8D:201C` / BROM `0E8D:2001` | Windows 设备管理器 |
| SELinux | `user` 版本、`test-keys` 签名 | `getprop ro.build.type` |

**Build 指纹**（比对用）：

```
alps/full_ailabs_s1l_8b/ailabs_s1l_8b:6.1.8-RS-20240326.2006/O11019/1711454715:user/test-keys
```

> ⚠️ 阿里对这台设备的系统做了深度定制（`adbd` 阉割、`pm` 命令删减、无未知来源安装入口）。不同 OTA 版本的定制点可能不同，**动手前先把自己的指纹记下来**。

## 环境准备（Windows）

1. **装 UsbDk**：双击 `UsbDk_1.0.22_x64.msi` → UAC 同意 → 一路 Next → **重启**
2. **关杀软拦截**：`MagiskPatcher.exe` / `mtkclient.exe` 常被 Defender 误杀，把工具目录加入排除
3. **路径纯英文无空格**：`D:\tmjl\` 这类路径，中文路径在部分工具里会炸
4. **数据线先自测**：用手机或 U 盘确认这根线能传数据 —— 只能充电的线是第一大坑

验证 UsbDk：

```powershell
Get-Service -Name "UsbDk"
Get-ChildItem "C:\Windows\System32\drivers\UsbDk*"
```

服务存在且驱动文件非空 = 装好了。

## 目录约定

下文用 `tools/` 表示你的工具目录，`backup/` 表示分区备份目录。示例：

```
D:\tmjl\
├── MTKClientV2.0\
├── crb_v221b\
├── Magiskpatcher\
├── app\              # 待注入的 APK
├── backup\           # 分区备份（17 个 .bin）
└── flash_out\        # 修改后的 system / boot
```
